# 画布内手动制作与分镜管理

用户要求把手动工作台和分镜管理放到无限画布，减少重复入口。本次只接界面与请求参数，沿用 Claude 的模型、镜头推荐和出片实现。

- `flow` 打开无限画布；`canvas` 打开同一画布并展开分镜管理；`comic` 定位同一画布的连续合成节点。切换保持作品、语言、制作类型和画布上下文。
- 顶栏直接进入手动出片；动态漫画复用视频节点的镜头方案，视频／自由创作可直接添加图片或视频生成节点。
- 分镜管理列出本版剧情镜头的首帧、视频、审核／过期／制作状态。编辑、手动出片、查看产物和连续合成直接定位画布节点；动态漫画未加入画布的剧情段按现有模板加入，并连接本版基础素材。
- 画布内改参数、引用、人物动作、首帧审核及生成任务全部沿用现有 Dock 与唯一任务轮询。镜头列表不另建生成器或轮询器。
- 手动通用生成展示网关实际声明的帧率与控制类型，明确提交所选帧率和控制类型；不支持的控制和帧率拒绝，不静默换成 24 帧或丢弃白模。刷新本机能力目录，使已上线的低帧率／Layout 控制在界面可选。
- 分镜列表展示真实产物状态；仅有视频不等于通过质量验收，不自动批准人数、身份、口型、动作或声音。
- 自由创作的连续合成沿用服务器 `concat` 配方，在节点里改镜头顺序、添加视频与预览，不跳入小说章节时间线。手动节点的编辑草稿、帧率与参考角色保存在画布，任务提交快照仍保持独立。

验收：前端类型检查及构建；帧率／控制参数边界测试；真实小说与动态漫画列表的编辑、定位、预览；自由创作直接新增手动节点；窄屏布局检查。
