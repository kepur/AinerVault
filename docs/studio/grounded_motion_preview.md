# 第一章五镜空间与运镜 V2

用户指出前一版没有运镜、人物站在墙上，要求按剧情自动选择帧率并优化空间关系。

## 原因与修正

前一版五镜脚本手动指定 4/8fps，多个镜头 `camera=hold`，角色卡只有轻微全身摆动。全身图片以固定画面百分比摆放，未校验脚底落点；绕腰摆动和整体呼吸位移会带动脚底。提升 fps 或单改提示词不能修复这些输入问题。

- `FloorPlane` 绑定到本版背景资产，记录地板多边形与地平线；当前只标定开场走廊这张背景，反向场景或其他场次需单独标定。
- 标准卡首帧按深度调整比例；自动站位落到墙上时移回地板并记录调整，手动指定的越界站位明确报错。参考图层动画检查脚底及走位路径，保持脚底锚点，加入接触阴影，按深度遮挡。
- 白模驱动使用同一地板标定与人物首帧位置，增加腿部步态以及共用镜头变换。它仍是屏幕投影的白模驱动，不等于 3D-BOX 中完整的几何场景；输入正确也不能保证生成模型永远不漂移，结果仍需逐镜验收。
- `comic.render_shot` 的自动选择：姿态对白 4fps，白模走位和一般接触动作 8fps，追逐/连续快速动作 12fps。自动是各镜头提交前选择，同一镜头内帧率固定。手动选择保留优先级；有明确走位的自动方案把 moves 传给白模路由。
- 以前统一写入提示词的“Locked camera, no zoom”改为明确镜头设置：推近、拉远、摇镜或固定。接触动作默认固定以便看清对象；镜头面板可改运镜，图层动画另有幅度、脚底位置和远近控件。
