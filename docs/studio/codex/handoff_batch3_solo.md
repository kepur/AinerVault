# 第三批交接：单人接手自由画布与素材联动

日期：2026-10-09。用户最新授权：“你先一个人继续完成未完成的”。本轮由 Codex 独立修改前后端，保留 Claude 已有导航与标准素材界面，不启动其他代理。测试仍交 Gemini。执行顺序更新于 `docs/studio/planA_execution_order.md`。

## 本轮已写入并加载的实现

1. 默认新建页签为空白，默认不关联当前章节；发送 blank:true/general，不继承 plan/镜头/场次；可选关联章节也不带计划。名称可省略，AI 规划独立为主动选项，不再预填人物示例和故事。创建响应 version 用于首次保存，消除写死 0 导致的冲突。创建/连线/保存不自动提交模型任务。
2. 无小说/章节/分镜也显示我的画布与编辑入口。画布列表合并全工作区与当前章节，直接打开任意 board_id 不再被章节自动选择链替换。载入采用画布实际 novel/chapter/plan，并清理旧 project/shot 上下文。新建/画布切换/小说章节计划切换/回首页均先等存盘完成，保存失败保留当前画布；快速多次切换只采用最后一次选择，避免丢掉当前修改。顶部补齐“我的画布”入口，回首页清理源上下文。
3. 独立画布素材抽屉调用 production/resources，分页列出真实实体/媒体，保留原来源。角色的真实世界/造型时期由 epochs 接口列出；单一时期可直接选择，多时期需明确选择。角色依照三视图+面部四视角+九宫格展示，缺格/近似映射如实显示。地点/道具不显示为人物 16 格。
4. 选择标准单格只写 kind/id/revision/binding/mode。重开通过 resolver 现取源媒体，不把展示 URL 当第二份素材。版本冲突显示原因；显式“采用素材最新版本”更新引用，不自动启动生成。复制生产引用节点保留同一源版本，删除节点不删素材。
5. 角色库可选择目标画布，也可新建真正空白画布，然后把已有单格直接加入目标。加入入口做行锁、board version、source revision、来源范围和世界检查。冲突时拒绝，不覆盖他人的画布文档；完成后跳回目标画布。
6. 音频支持上传、引用、原生播放与保存；新增音频节点类型及布局/复制/删除。音频驱动生成尚未接入，相关生成参考操作明确提示不支持。
7. 两个真实生成入口均接上源引用：配方执行器及普通 /studio/generate 先检查生产引用版本/绑定，使用真实 AssetID 和源地址；分组可以展开生产引用，过期/缺失不能静默当作缓存图片。普通入口请求增加 refs[].production_ref 和 target.board_id，旧请求保持兼容。
8. 配方缓存包括直接/间接生产源引用版本；明确采用新版源后，下一次运行重新计算。单独运行下游时，失效的上游配方一起排队，避免继续消费旧的中间结果。
9. 角色整包生成可附带 canonical binding；后台完成后以版本/锁定检查将真实单格和拼版写入当前时期。页面关闭不会阻止服务端完成绑定。期间源包改变则保留生成素材并报绑定冲突，不覆盖新造型。缺格仍显示缺格，未审核仍是 bound_unreviewed。原来不带 binding 的独立生成保持原行为。
10. canonical-pack 与 stage/card 共用 physical 推断规则；来源仍标 user/inferred/default，估算不等于用户物理标定。

## 给 Gemini 的独立验收路径

1. 以不带 novel/chapter/plan 的真实 /studio/?view=flow 进入；新建不填写任何字段。确认服务端 doc=0 nodes/0 edges、version=1，UI 无自动节点、无任务提交。
2. 从现有章节中再次默认新建，确认新画布不带 plan/novel/chapter，默认不勾关联；用户主动勾章节时也必须是空文档且 plan=null。
3. 手工添加文字、上传图/视频/音频、连线、拖动、分组、复制、删除与撤销。等待保存，刷新/切换/回首页/直接链接重开，确认内容/引用/布局/视口保留；不能只用模拟 session。
4. 在独立画布分页浏览同工作区的实体/媒体。选择角色世界+时期单格，重开仍是同一 ref/AssetID。多时期不自动猜；缺图不能当可用单格；近似图有提示。
5. 从角色库选择一张独立或章节画布，点击“用到画布”，确认新增引用真实落库、回到正确画布，修改不是下载后重上传。两个标签页同时写入应得到冲突，不能覆盖。
6. 源包/源图更新或删除时：旧引用保留 revision，resolver 显示冲突/缺失；不自动改世界/时期。显式采用最新版本后，配方 hash 改变，运行下游包含失效上游。测试分组内生产引用与复制源节点。
7. 对 /studio/generate 与 :execute 分别验证实际消费者使用源 AssetID，篡改缓存 URL 或过期版本不能绕过检查。没有 board_id 的生产引用必须拒绝；旧非生产引用请求仍可用。先做隔离配置的无 GPU 检查，任何真实生成另按用户的排队要求执行。
8. 在允许生成的隔离环境确认标准整包 outputs→epoch.canonical_views 真正写回、页面关闭后仍绑定；生成期间修改包、锁定、删除时期均应保留产物而拒绝覆盖。输出审核与角色一致性仍需独立视觉检查。
9. 原小说分镜画布、自动按场次、demo 模式、角色库普通造型和导航的回归。首次保存必须按响应版本；演示空白创建/列表/存档也保持同样语义，不能与真实后端混调。
