# Ainer Studio 统一创作空间

## 入口与分类

`/admin` 转到 `/studio/?view=hub&hub=production&workspace=novel`。旧后台页通过同源嵌入沿用原有接口；左侧主导航和顶部作品上下文由 Studio 统一提供。后台内部跳转同步外层 URL，进入画布时仍携带小说、章节、语言、制作类型及各版画布引用。

- 小说制作：制作总览 → 世界观／翻译／定稿剧本 → 本版基础素材 → 无限画布／3D 舞台／章节分镜 → 验收与成片。
- 自由创作：独立画布、独立舞台、公共风格与运镜库。小说上下文不自动带入。
- 视频和动态漫画共用故事来源，分别保留人物与素材、画布、制作项目及白模项目。
- 模型设置、公共参考库和全局任务作为管理工具收起。自由创作的画布素材库只列独立素材。

`workspace=novel|free` 表示分类，`medium=video|comic` 表示小说制作版本，`view=hub&hub=<原后台页>` 表示同一外壳中的旧工具。各分类与版本记住各自最近上下文；画布切走前先完成存盘，保存冲突时保留当前页。

## 3D 项目归属

新项目沿用现有 `novel_id`、`shot_plan_id`，制作版本与章节写入现有 `settings_json.studio_medium/studio_chapter`。旧白模通过镜头当前导演引用、导演场景保存的镜头引用、小说画布中的白模引用反查归属；此过程只读，不迁移或删除旧项目。

列表与直接打开编辑器均检查分类及版本。未归属小说的项目在自由创作中使用。模板可在任一分类创建独立项目。

## 画布布局

漫剧按剧情、素材、站位、对白、分镜、视频、尾帧和合成分列；后续剧情按行展开。自由创作按连接依赖分列，参考实际节点尺寸避让。钉住的节点与分组保持位置。新增后续漫剧段落会整理布局，也可手动点击“整理布局”。

节点内继续引用当前剧本、标准卡和本版产物，不复制来源数据。旧角色库引用到画布时也只列当前小说的非漫剧画布。

## 验证与边界

已用实际浏览器验证：总览、剧本、后台内部切页、视频／漫剧切换、自由创作切换、现有 3D 编辑器及窄屏导航。当前漫剧画布保留 16 个节点、27 条连接；配置和节点布局保存到服务端。2026-10-11 的现有 76 个白模项目根据可追溯引用分为 39 个小说项目和 37 个自由项目。

本次统一界面与入口，没有调整模型推理速度。动态漫剧的三维白模控制到生成模型仍按现有能力提示处理，不能因 3D 编辑器已集成就将其视为已经接通。镜头质量仍需逐镜验收，当前项目尚无通过验收的完整成片。
