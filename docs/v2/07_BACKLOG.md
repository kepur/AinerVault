## A. 剧本层：对话关系与表演信息

### 现状

v2 的 `ScriptBlock` 有 `speaker_tag`，知道**谁在说**，不知道**对谁说**。
`WorldEntity` 有 `appearance` / `voice_hints`，是角色的**恒定属性**，
不是某一刻的**瞬时状态**。

v1 更弱：`skill_03_scene_shot_plan.py` 用正则数关键词
（`action_hits` / `dialogue_hits` / `emotion_hits`），按命中数分类场景，
时长一律 `default_shot_duration_ms = 3000`。没有站位、没有对话指向、
没有表情动作与人物的绑定。**这套设计 v1 并不存在，不是移植而是新建。**

### 缺口

从剧本到分镜图，中间缺一层「这一刻画面里发生什么」：

| 维度 | 说明 | 为什么不能省 |
|---|---|---|
| 对话指向 | 谁对谁说，在场还有谁不说话 | 决定镜头给谁、给几个人 |
| 站位 | 人物在画面中的相对位置与朝向 | 前后帧站位跳变，动画就是穿帮 |
| 表情 | 该角色此刻的面部状态 | 同一张脸不同表情，i2i 才有变化 |
| 动作 | 此刻的肢体动作与手持物 | 首帧到尾帧的动作差就是这一镜的运动 |
| 视线 | 看向谁/什么 | 对切镜头的轴线靠它定 |

### 依赖顺序

素材基础包（人物/道具/服装的目标文化定形）必须先有，
表演信息才有附着对象 —— 说「他握紧了剑」时，
「剑」得先是一个有确定形态的素材，否则每一镜画出来的剑都不一样。

### 时长

前后分镜之间那几秒该多长，两条来源：

- **按剧情幅度自动**：`StoryBeat.tension_level` 与 `emotion_intensity` 已在库里，
  配合 `DirectorProfile.avg_shot_ms` 的分布，用赤字法分配 —— 张力高的段落切碎，
  张力低的给长镜头。这套在 `shot_plan` 里已有雏形。
- **人工覆盖**：任何一镜可手动设时长，锁定后自动分配不再改动它。

对白镜头例外：TTS 的真实时长是权威。语音说完了画面还在等，
或话没说完就切镜，都是硬伤 —— 所以 `AudioSpec.duration_ms` 反向决定
`Shot.duration_ms`，不参与自动分配。

### 落地拆解

1. `shot_performance` 表：shot × entity → 站位 / 表情 / 动作 / 视线 / 手持物
2. 剧本层补对话指向：`ScriptBlock.addressee_tags`、`present_entity_ids`
3. 抽取管线加一步「表演抽取」，从原文抽这一刻的瞬时状态（区别于恒定属性）
4. 首帧提示词组装读 `shot_performance`，尾帧按动作差做 i2i
5. 站位连续性校验：相邻镜同一角色的站位跳变要报警

## B. 称呼在呼语位与叙述位的形式差

已实现的称呼变体给每条称呼一个目标形式，但英语里同一称呼在两个位置形式不同：

    呼语位：'Master, I shall go.'        ← 直接称呼，裸用
    叙述位：His master pushed the door.  ← 作主语，要带限定词

当前模型只给一个形式，叙述位会译出 `Master pushed open the door`，读着别扭。
需要在 `entity_appellations` 上区分 vocative / referential 两种形式。
