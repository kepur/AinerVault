# 制作脑审片标准 v0（hub.P1.C1）

状态：Codex 设计提议，2026-10-15，待平级审议；未接执行器/质检服务。依据 D-011/D-012、NORTH_STAR §3、R5 §8、10_PRODUCTION_BRAIN.md。适用于固定 plan/world/take/shot/媒体版本；不解冻旧 Critic 或反馈环。

## 七维度和证据

| 维度 | 检查 | 必需证据 |
|---|---|---|
| 意图与题材 | 用户目标、题材效果、信息何时揭示 | brief、节拍/观众知识计划、完整片段和声音；单帧不足以证明悬疑/喜剧成立 |
| 年代与世界设定 | 服饰道具、技术、机制、角色可知范围 | 固定世界版本/规则包、资料来源、相应画面；现实/架空/角色相信分别记 |
| 剧情与人物 | 因果动机、秘密、反应与连续性 | NarrativeIR/事件、表演轨、前后文、完整片段；推断标不确定 |
| 摄影与剪辑 | 镜头目的、主体可读、时序、视线/动作与转场 | Coverage/相机、切点、连续帧和带声音片段；有意破例附意图 |
| 美术与身份 | 角色/服装/形态、线条/光影/五官层次、跨镜稳定 | 身份和风格摘要、形态事件、代表帧/通道；美术层和世界层分开 |
| 声音与表演 | 对白可懂、角色音色、口型、视线/表情/反应时序 | 实际音频及其时间轴/哈希、控制轨和视频；静音不得给声音通过 |
| 执行与体验 | 实际命令成功、编辑/回放、交互/延迟/资源 | 消费者日志/状态/媒体元数据、实测操作与成本；源码存在不代表E2E通过 |

## 判定规则

硬约束单独逐条记成立/不成立/未验证：执行成功、身份、用户锁定字段、已登记规则和门、来源许可、世界事实与呈现分离。任一硬约束不成立为不合格；必要证据缺失为未验证，不能取其余维度平均分抵消。已有门沿用原登记，不发新阈值、不把 Gate ID/S 的部分回归扩成全门通过。

美术、叙事和题材效果是候选之间的对比目标。v0采用成对偏好/平局/无法判断及理由，不捏造“专业级80分”。评审先看要求再看片；允许记录主观意见和分歧。未登记的评分尺度不能拿来宣布进步。

创作者自评只用于有界搜索；晋升要非作者评价和既定治理。记录评审者/模型版本、提示与标准摘要、输入媒体/样本身份、顺序和评价日期。换评价器必须让新旧评价器看同一固定基线和候选，分开报告；不能把评价器更宽松当作模型或作品变好。

## 每个问题是局部可追溯记录

问题记录字段：issue_id、standard_version、plan_id/revision、world_id/version、scene/revision、take_id、shot_id、角色/实体ID、时间区间、维度/类型、严重度、判定、证据引用、实际观察、预期要求、建议修改范围/路径、锁定影响、依赖与未验证项、评审者、后续修订引用。

时间必须声明 sim_tick（120Hz）或 video_frame（附fps/起点）或 audio_sample（附sample_rate），区间统一左闭右开；不可用“第300帧”混称300tick。证据引用含路径/资产ID、摘要及帧/时间定位；不附无来源总分。

严重度为 blocker（硬约束失败）、major（妨碍叙事/理解/体验）、minor（局部修饰）、note（建议或未验证提醒）。严重度不是科学门阈值。建议修改只能选 world / performance / presentation / style，并给最小范围；改世界走统一信封与新版本，不直接修图伪造接触事件。修一处先核受影响依赖，不默认重做整段。

美术问题尽量定位角色包/风格包控制项：外/内/脸部线条、阴影分量、灯光组/链接、脸部法线、五官深度层次、二次运动覆盖。D5尚未给定的控制名写待D5，不能声称后端已可调。

## 执行证据与视觉判断

位置、接触、时间、动作类型、朝向及锁定身份先读AWZ/Hub权威执行数据与实际绑定；再以画面核对渲染是否正确表达。执行数据与画面矛盾要报问题，不能用执行成功替代可见效果。画面美感、表情和表演质量由视觉评审和用户判断；视觉模型对朝向/动作的猜测不能覆盖真实状态。

例如“没看向书包”：检查gaze目标和时间、骨骼/相机视角及渲染帧；分别标控制未执行、视角遮挡或表演不明显，不凭一张图修改人物位置。

## 用户品味与制作经历

用户选择/修改是最高品味依据，绑定当时要求、候选身份、差异、用户原话、顺序、实际成本与选择时间。用户偏好不会撤销硬约束或授予许可/训练预算；偏好变化保留上下文而不覆盖旧记录。完整经历链为要求→计划→执行→问题→局部修改→用户选择→实际结果。以后进入训练还要过来源、许可、分区与运行登记，当前不训练。

## 同世界悬疑/喜剧盲评

固定同一事件、世界版本与角色身份；允许不同take/镜头/声音处理，分别记录，不伪称相同take。第三方准备匿名A/B与随机顺序，隐藏作者、技法名、模型和自评分；评审知道当前要评价的题材目标，但不知道哪版用了何种手法。先查硬约束，再分题材判断信息差/延迟揭示或预期/停顿/反应是否可感；记录平局与无法判断。再揭盲核技法实际执行，避免因“用了某技法”就给作品加分。当前没有真实成片盲评结果。

技法库条目引用 `tech_id@version`、适用条件、可检查信号与反例。信号只能证实手法被执行（如停顿发生于指定区间、反应镜头覆盖目标角色），不能证明观众一定发笑或紧张。无执行日志则未验证；用户明确否定效果仍保存。后续实现/复核分别登记，不将本稿计为审片系统已可用。
