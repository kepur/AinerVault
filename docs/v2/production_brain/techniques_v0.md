# 技法库 v0.1：稳定引用编号，与制作计划对齐

- 版本：v0.1 · 数量：27 · 与 `techniques_v0.json` 同内容，机读以 JSON 为准。
- 每条示例都用同一事件“书包变大象”（悬疑版/喜剧版/冷幽默版至少其一）。
- 来源只写通用电影理论名词或书名，不大段抄录受版权保护的文字；来源署名均为暂记，未经独立核实（见来源说明），不作为学术引用，未下载或捏造引用。
- `id`（N1等24旧id）保留不改；`ref`为稳定引用，格式`tech:<类>.<名>`，类只用narrative/comedy/edit/camera/anim；`aliases`为空表示暂无别名；顶层`ref_index`为`ref`与`aliases`到`id`的映射，无重复键。
- `timing`/`verified_by`为null表示本条未单独设全局时机/核对方，核对分工见各可检查信号注明的责任（执行数据核对/视觉审片）；缺数据时判unknown，不视为通过。
- 执行要求与timing中的具体秒数/帧数除已登记门外均为审美示例，具体值由具体计划选择并记录；多技法时长并用冲突时不得暗自合并或改全局阈值，具体时长由具体制作计划在beats/shots中选择并记录；已有登记门不改，不新增全局科学门。
- 本库仅为文本规则，未验证实际编译/表演/审美有效性。

## 叙事（6 条）

### N1 信息差
- 引用：`tech:narrative.information_gap`；别名：无
- 作用：让观众与角色掌握不同信息，产生悬念或优越感
- 何时用：悬疑、喜剧误会开场前先分配谁知道什么；何时别用：群戏每人信息都不同且无主线时别用，易乱
- 前置：世界系统能查询每个角色的可见事件集
- 执行要求：走位[知情者与不知情者分处镜头内外，视线错开] 时序[情报镜头在事件前≥3秒出现] 表情[不知情者自然表情，待 hub.P1.D1 表演接口] 注视[不知情者视线避开关键物] 景别[先给观众情报的近景，再切回全景] 切点[情报镜头与主镜头间硬切（cut/continuous），具体切点由具体计划shots.transition记录；本条不另行指定切法] 声音[情报时刻加弱音效提示，待声音设计] 表现效果[无]
- 可检查信号：知情/不知情名单以制作计划narrative.knowledge为准，与执行数据可见性对照核对（责任：审片对照核对；缺knowledge标注或缺可见性执行数据时判unknown，不视为通过）；观众先行情报镜头出现次数≥1，每次≥1秒（来源：执行数据切点时序；责任：执行数据核对；缺切点时序时判unknown）
- 时机：null（见顶层约定）；核对方：null（见各信号责任）
- 常见失败：全员全知，悬念泄漏；信息差无视觉交代，观众以为穿帮
- 示例（书包变大象）：悬疑版：观众先看到书包拉链里伸出象鼻（1.5秒特写），主角还没发现，继续背着书包走。
- 可执行技能：待建：世界系统角色观察范围查询（谁看见什么，awz.P3.I1）；适用版本：世界系统交互运行（待 awz.P3.I1/I2）；Blender 5.2 现有
- 反例：反派密谋时给全景长镜头把纸条内容直接拍清，信息差失效。
- 来源：叙事学聚焦理论（热奈特）；《电影语言》（马赛尔·马尔丹）

### N2 伏笔与回收
- 引用：`tech:narrative.foreshadow_payoff`；别名：无
- 作用：让观众事后觉得“原来早有提示”，增强可信与满足
- 何时用：反转、变形类事件必须提前埋视觉伏笔；何时别用：单场短片无回收空间时别硬埋
- 前置：剧本已标出伏笔对象与回收点
- 执行要求：走位[伏笔物放在主角动线必经处] 时序[伏笔分布在回收前至少2个节拍] 表情[人物不看镜头，保持自然] 注视[主角视线扫过伏笔物不停留] 景别[伏笔用细节插入（近景/特写），回收用同角度回闪] 切点[回收用匹配剪辑回呼伏笔构图] 声音[伏笔处环境音正常，不加预告性音乐] 表现效果[无]
- 可检查信号：每个回收至少对应2个伏笔镜头（来源：制作计划伏笔-回收关联标注加执行数据镜头清单；责任：审片对照核对；缺关联标注时判unknown）；伏笔总时长≥3秒（来源：执行数据切点时序；责任：执行数据核对）；回收回闪构图与伏笔的对应关系由视觉审片对照确认是否同角度回闪（责任：视觉审片；缺对照或无审片结论时判unknown，不设全局数值门）
- 时机：null（见顶层约定）；核对方：null（见各信号责任）
- 常见失败：伏笔只出现半秒，观众记不住；回收时镜头不回呼，观众对不上
- 示例（书包变大象）：悬疑版：第1镜书包侧面象纹特写2秒，第3镜同纹样再出现1.5秒，第5镜书包变大象时切0.5秒回闪第1镜构图。
- 可执行技能：待建：制作计划伏笔-回收关联字段（awz.P3.J1）；适用版本：制作计划契约（待 awz.P3.J1）；Blender 5.2 现有
- 反例：书包上的象纹一闪而过0.3秒，结尾变大象时观众毫无印象。
- 来源：剧作理论（契诃夫之枪）；《故事》（罗伯特·麦基）

### N3 反转
- 引用：`tech:narrative.reversal`；别名：无
- 作用：让观众预期落空后重组理解，产生强烈记忆点
- 何时用：中段或结尾需要记忆点时，全片限1–2次；何时别用：10分钟内反转超过2次，观众疲劳时别用
- 前置：N1信息差+N2伏笔已就位；变形事件已登记
- 执行要求：走位[反转物先藏于盲区，揭示时进入主角视线中心] 时序[铺垫≥15秒，揭示2–4秒，反应3–5秒] 表情[主角震惊表情，待 hub.P1.D1] 注视[揭示瞬间主角视线钉住变形物] 景别[揭示用近景或特写，之前用全景藏信息] 切点[揭示用跳切或匹配剪辑，制造断裂感] 声音[揭示前0.5秒静音，揭示后加音效] 表现效果[轻微速度线（表现效果，不改世界事实）]
- 可检查信号：反转前至少2个伏笔镜头可数；反转揭示镜头时长2–4秒，由执行数据核对切点时序
- 时机：揭示点停留2–4秒，前后各留0.5秒静默；时序由执行数据核对，表情由视觉审片核对；核对方：执行数据（切点时序）+ 视觉审片（人物反应）
- 常见失败：反转无伏笔，变成机械降神；反转后人物动机对不上
- 示例（书包变大象）：悬疑版：前4镜都按“书包丢了”拍，第5镜揭示书包变成小象一直跟在主角身后（延迟揭示式反转）。
- 可执行技能：待建：世界系统变形事件显式记录（awz.P3.I1，书包变大象事件）；适用版本：世界系统交互运行（待 awz.P3.I1）；Blender 5.2 现有
- 反例：书包突然变大象却无任何伏笔和动机，观众只觉得乱。
- 来源：剧作理论（麦基的揭示与反转）；悬念与惊奇研究（希区柯克访谈）

### N4 延迟揭示（悬念）
- 引用：`tech:narrative.delayed_reveal`；别名：无
- 作用：让观众等待揭示，放大不安与好奇
- 何时用：悬疑版书包变形前制造不安；何时别用：喜剧节奏段落别用，会杀笑点
- 前置：声音与灯光可独立调度
- 执行要求：走位[人物走向声源但镜头不跟，只给背影] 时序[征兆3–6秒，揭示2–3秒] 表情[人物不安表情渐强] 注视[人物视线寻声，观众看不到声源] 景别[延迟段只给人物反应与环境空镜，不给本体] 切点[延迟段用 J-cut 声音先行] 声音[低鸣+脚步声渐近，揭示时戛然而止] 表现效果[无]
- 可检查信号：声音/征兆先于揭示≥3秒（执行数据）；揭示前观众视角镜头≥2个
- 时机：null（见顶层约定）；核对方：null（见各信号责任）
- 常见失败：延迟太长变拖沓；延迟期间无新信息，观众快进
- 示例（书包变大象）：悬疑版：先听到 书包里传出低鸣（只闻其声3秒），走廊灯闪2秒，仍不给书包镜头，第6秒才切书包抖动特写。
- 可执行技能：待建：声音先行+延迟揭示剪辑模板（hub 剪辑技能，待建）；适用版本：Blender 5.2 现有；世界系统事件时序（待 awz.P3.I1）
- 反例：异常声音响了20秒还不揭示，观众已经猜到且厌烦。
- 来源：希区柯克悬念论；《电影剪辑》（唐·费尔）

### N5 动机建立
- 引用：`tech:narrative.motivation_setup`；别名：无
- 作用：让观众相信人物为何行动，变形才可信
- 何时用：主角与变形物的关系必须先立动机；何时别用：群演路人不需要动机戏
- 前置：角色小传与目标已写入制作计划
- 执行要求：走位[动机动作用重复走位强化（如抱书包两次）] 时序[动机戏每段3–5秒，共≥2段] 表情[珍视/紧张表情] 注视[视线不离书包] 景别[动机用中景全身，强调身体动作] 切点[动机段之间硬切，具体由具体计划shots.transition记录；本条不另行指定切法] 声音[日常环境音] 表现效果[无]
- 可检查信号：动机行为在变形前出现≥2次；动机台词≤1句，其余用行为表达（视觉审片）
- 时机：null（见顶层约定）；核对方：null（见各信号责任）
- 常见失败：动机只用台词交代，无行为支撑；动机与后续行动矛盾
- 示例（书包变大象）：悬疑版：开场10秒主角把书包抱紧（怕丢），中段书包变小象后主角仍护住它——怕丢的动机延续到护象。
- 可执行技能：待建：角色目标与记忆状态机（世界系统角色运行，待 awz.P3.I1）；适用版本：角色包 v2（待 P3-D5）；Blender 5.2 现有
- 反例：主角说最怕大象，转头却主动抱住象鼻，动机崩了。
- 来源：斯坦尼斯拉夫斯基动机理论；《故事》（罗伯特·麦基）

### N6 反差
- 引用：`tech:narrative.contrast`；别名：无
- 作用：用大小/情绪/节奏的落差放大变形冲击
- 何时用：冷幽默与悬疑揭示时放大冲击；何时别用：现实主义题材慎用大反差
- 前置：前后两段的基调已定
- 执行要求：走位[小书包与大象同框站位，人物夹中间显小] 时序[反差揭示2–3秒] 表情[人物平静 vs 环境夸张] 注视[人物视线平视，不抬头看大象] 景别[前段特小景别，后段突然大全景] 切点[硬切制造落差] 声音[前段极静，后段只加一声象鸣] 表现效果[无]
- 可检查信号：前后段声压差≥10dB或景别差≥2档（声压来源：执行数据声轨，景别来源：执行数据镜头景别；责任：执行数据核对；缺声轨或缺景别标注时对应项判unknown，不视为通过）；反差切点位置来自执行数据切点时序，与前后声压/景别取值对照核对（责任：执行数据核对；缺切点时序或缺声压/景别标注时判unknown）
- 时机：null（见顶层约定）；核对方：null（见各信号责任）
- 常见失败：反差过大变成跳戏；反差无过渡，观众出戏
- 示例（书包变大象）：冷幽默版：全片最小声的图书馆里，书包无声变成三米大象，主角仍小声说“嘘——别出声”。
- 可执行技能：待建：景别与声压对比剪辑模板（待建）；适用版本：Blender 5.2 现有
- 反例：前一秒恐怖追杀，下一秒无理由切到书包变大象卖萌。
- 来源：对比蒙太奇（爱森斯坦）；喜剧反差理论（柏格森）

## 喜剧（6 条）

### C1 建立预期再打破
- 引用：`tech:comedy.setup_expectation`；别名：无
- 作用：让观众的预期落空，产生笑
- 何时用：喜剧版变形前必备；何时别用：悬疑段落别用，会泄悬念
- 前置：重复节拍≥2次已拍
- 执行要求：走位[同一位置重复同一掏书包动作] 时序[重复段≥2次（示例：三次重复共6–9秒，每段2–3秒），打破1–2秒；具体次数与时长由具体计划选择并记录] 表情[主角从习以为常到瞪眼] 注视[打破瞬间视线钉住象鼻] 景别[重复用同一中景，打破切特写] 切点[打破用跳切加速] 声音[重复段用同一音效，打破点变调（示例：前三次同一音效，第四次变调；具体次数随计划）] 表现效果[打破瞬间加速度线（表现效果）]
- 可检查信号：预期重复≥2次且动作一致（来源：执行数据；责任：执行数据核对；缺执行数据时判unknown；示例为三次重复，每段2–3秒，具体次数由具体计划选择并记录）；打破点后反应镜头≤1秒内接入（来源：执行数据切点时序；责任：执行数据核对；缺时序时判unknown）
- 时机：重复节拍每段2–3秒（示例），打破点停顿0.5–1秒后接反应；时序由执行数据核对，笑果由视觉审片核对；具体时长由具体计划选择并记录，不与其他技法时长暗合并；核对方：执行数据（节拍时序）+ 视觉审片（反应）
- 常见失败：预期没立住就打破，观众无感；打破后无反应镜头，笑点落地失败
- 示例（书包变大象）：喜剧版：主角连续三次拉开书包拿出课本（建立“普通书包”预期），第四次拉开伸出一只象鼻卷走课本。
- 可执行技能：待建：重复动作节拍模板（hub 导演技能，待建）；适用版本：Blender 5.2 现有；角色包 v2（待 P3-D5）
- 反例：书包还没演出“普通”就直接变大象，观众没有预期可破。
- 来源：不一致-消解幽默理论；《喜剧的秘密》（作者署名待核，原暂记“成长”）

### C2 停顿加反应
- 引用：`tech:comedy.pause_reaction`；别名：无
- 作用：用停顿放大荒谬，再用反应告诉观众可以笑
- 何时用：每次喜剧变形后都要接；何时别用：悬疑追逐戏别停
- 前置：反应人物已在场
