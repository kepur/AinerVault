## 焦段
18–24mm 广角（空间大、透视强、适合追逐与环境）；35mm 标准（跟拍、中景）；50mm 人眼；
85mm 人像特写（背景压缩、虚化）；135mm 长焦（偷拍感、压缩空间）。

## 中文说法 → 运镜预设（S.cameraPreset 的名字）
- 推／镜头前推 → push_in；拉／镜头后移 → pull_out；推轨 → dolly_in；推轨至中景 → dolly_to_medium
- 远景推近 → wide_push_in；大远景到特写 → extreme_wide_to_close；中景到远景 → medium_to_wide
- 变焦推进 → zoom_in；变焦拉远 → zoom_out；柯克变焦／希区柯克变焦 → dolly_zoom
- 左摇／右摇 → pan_left / pan_right；上摇／下摇 → tilt_up / tilt_down；甩镜 → whip_pan
- 左移／横移 → truck_left / truck_right；上升／下降 → pedestal_up / pedestal_down；摇臂上升 → crane_up；摇臂 → jib
- 跟随拍摄 → follow；背跟 → follow_back；背跟特写 → follow_back_close；正面跟 → follow_front；
  正面跟远景 → follow_front_wide；侧跟推近 → follow_side_push；远景跟随 → follow_wide；
  正面转背跟 → front_to_back；顶拍转跟随 → top_to_follow；第一视角 → first_person
- 左环绕／右环绕 → orbit_left / orbit_right；环绕 → orbit；半弧 → half_arc；环绕两周 → orbit_twice；
  环绕推近 → orbit_push；螺旋上升／盘旋抬升 → spiral_up；盘旋下降 → spiral_down；推近左转 → push_turn_left
- 无人机 → drone；高空航拍 → aerial_high；航拍拉升 → aerial_rise
- 固定镜头 → static；手持 → handheld；荷兰角 → dutch；滚筒旋转 → roll

## 剪辑节奏
- 动作戏：每镜 1–2.5 秒，景别跳跃大；对话戏：每镜 2–4 秒，正反打。
- 切点落在动作中间（车刚转弯、人刚出拳）比落在静止处更顺。
- 180° 规则：两人对话或追逐时，所有机位留在两人连线（或运动方向线）的同一侧，
  否则前后镜头里人物/车辆的左右方向会反。
- 一场戏先给一个全景把空间交代清楚，再进中近景。
