# 端到端冒烟语料

三章武侠短篇，两千字。不是随手写的样本 —— 每一章都为特定的管线环节准备了素材：

| 要验的 | 语料里的东西 |
|---|---|
| 称呼变体 | 沈砚被叫作「砚儿」（师长）、「沈镖头」（同行）、「姓沈的」（敌意） |
| 家族共姓 | 沈砚 / 老周 / 柳三娘，三个不同姓氏 |
| 伏笔链 | 三簧锁（①埋）→ 官银的规矩（②解释）→ 腰牌（③揭晓） |
| 说话人边界 | 「总镖头把镖单推过来，指节在桌上敲了两下：」这类长叙述句开头 |
| 名物 | 镖局、趟子手、镖旗、通关文牒、驿站、腰刀、绿林、官银、漕帮 |
| 笑点 | 老周的炒豆与「上个月我赢了」 |
| 反转 | 结尾腰牌的归属 |
| 对话在场 | 第③章三人同场，其中一人长时间沉默 |

改语料前先想清楚会失去哪一项验证。
